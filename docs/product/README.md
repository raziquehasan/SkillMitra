# Product Documentation

This directory contains product and UX documentation for SkillMitra.

## Planned Documents

- `product-vision.md` — Vision, mission and goals
- `user-personas.md` — Stakeholder personas (candidates, employers, trainers, government)
- `user-stories.md` — Feature user stories mapped to personas
- `wireframes.md` — UI wireframes and design references
- `feature-roadmap.md` — Phased feature delivery roadmap

## Stakeholders

| Stakeholder | Role |
|---|---|
| Candidates | Career guidance, skill gap identification |
| Employers | Demand signaling, validation |
| Training Providers | Curriculum alignment, trainer planning |
| Government / Districts | District-level training plans, policy insights |
| Platform Admins | Data management, system oversight |
